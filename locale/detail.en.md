After the assistant finishes, leave the composer empty to see a gray follow-up suggestion. Press **Enter** to insert it as a draft, then edit and send it. Press **Esc** to dismiss the suggestion.

The plugin uses the model and credentials already configured in DSH. Each new suggestion makes one extra model request. See this page’s usage section for suggestion tokens and estimated costs.
